# Next 72 Hours — token- and hardware-constrained sprint

Supersedes the previous version. Optimized around the two real constraints:
finite agent tokens this week, and a 2.6GB-RAM Chromebook. Ordering principle:
**outside-human contact before anything else**; agent-token spend only where
a human can't do it faster.

## Day 1 — contact first (agent tokens: near zero)

1. ☐ Operator: send outreach to prospects 1–3 (OUTREACH.md archetypes;
   the message is already written — do not edit it again)
2. ☐ Operator: paste condensed ONE_PAGER into 2 permitted communities
3. ☐ Agent (if tokens remain): nothing. Day 1 is a human day by design.

## Day 2 — proof on standby (agent tokens: medium)

4. ☐ Agent: refresh portfolio numbers (run flywheel) so any prospect who asks
   sees current data
5. ☐ Agent: render ONE_PAGER → `site/flyer.html` print-friendly one-page
   version (screenshot-able, no hosting needed)
6. ☐ Operator: send to prospects 4–5; reply to any Day-1 response within hours
   (speed is the differentiator, not polish)

## Day 3 — delivery readiness (agent tokens: medium)

7. ☐ Agent: dry-run the full engagement chain once, end to end, on self:
   mini-intake → triage_report.py → human-pass placeholders → EMAIL_TEMPLATES
   §2 delivery email. Fix anything janky.
8. ☐ Operator: 1–3 free triage calls (TRIAGE_CALL_SCRIPT.md). For each:
   quote the tier, send Form A (pilot agreement) if they bite.

## Day 4 — buffer & ledger (agent tokens: low)

9. ☐ Agent: commit everything, push, tick ROADMAP boxes that are actually done
10. ☐ Operator: log the week's contacts in OUTREACH.md pipeline board
11. ☐ Rule check: if zero outside-human reactions after 8+ contacts, spend
    remaining tokens on rewriting the MESSAGE (not the tooling) per
    WINTER_CASH_PLAN week-1 metric

## Token budget rules (until limit resets)

- Every agent task must either (a) enable a send, (b) speed a delivery, or
  (c) close a ledger. Everything else waits.
- No new tools, no new docs, no refactors this week. The kit is complete;
  the funnel is empty. Fill the funnel.
- If choosing between generator polish and a prospect email: email. The
  slapdown is doctrine now.
