# CLIENT FORMS — fill-in templates

## Form A: Pilot-pricing agreement (email or printed, one page)

```
CONSTRAINTOPS — SERVICE AGREEMENT (PILOT)

Between:  ConstraintOps ("the practice"), [operator name]
And:      [client name], [contact email]
Date:     [date]

SERVICE
  [Service name], as described in [service sheet filename], delivered to
  the scope discussed on [date of call / thread]. Deliverable: the written
  report + debrief call. Anything beyond the listed deliverable is a new
  agreement, not scope creep.

PRICE & TIMING
  Pilot price: $[amount] (standard: $[amount]) — discount given in exchange
  for: (tick) [ ] testimonial permission  [ ] referral introduction
  Turnaround: [N] business days from receipt of requested materials.
  Payment: [payment method], due on delivery of the report.

WHAT THE CLIENT PROVIDES
  [list: transcript locations / project root / access notes — from INTAKE]
  Delays in materials move the turnaround day-for-day.

CONFIDENTIALITY
  Everything the client shares stays with the practice. Nothing is published,
  quoted, or referenced without written permission. Reports may contain an
  anonymized excerpt used as portfolio sample ONLY if [x] below is ticked:
  [ ] Permission granted for anonymized portfolio excerpt (identifiers removed)

HONESTY CLAUSE (the practice's commitment)
  All findings ship with raw evidence and re-verification commands. If any
  finding cannot be reproduced by the client, the practice will correct or
  refund at the client's choice. No outcome guarantees are made or implied.

Both parties agree:  [client name/date]   [operator name/date]
```

## Form B: Testimonial capture (send after they confirm permission)

```
Thanks for agreeing. Three prompts — answer any subset, one line each is plenty:

1. THE BEFORE: What was happening (or not happening) that made you reach out?
   [ free text ]

2. THE MOMENT: What did the report/call change or clarify for you?
   [ free text ]

3. THE AFTER: What's different now, in plain words?
   [ free text ]

Permission block (tick all that apply):
  [ ] I approve quoting the above, attributed as: [name / role / "anonymous"]
  [ ] I approve quoting the above, unattributed
  [ ] You may include my first name + industry only

Signed/confirmed: ______  Date: ______
```

## Usage rules

- Form A is signed BEFORE work starts on any discounted engagement — the
  discount *is* the trade for the testimonial/referral; state it, don't hope it
- Form B goes out 2–3 days after delivery, once they've used the report
- Both forms stored in `ConstraintOps/clients/[client-name]/` with the report
- A client who ticks neither portfolio box still gets full service — the
  honesty is the brand; never condition delivery on marketing permission
